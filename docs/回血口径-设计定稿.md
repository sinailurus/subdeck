# 回血口径功能设计定稿（2026-11-23 TA 拍板，Docker 抢先版）

## 数据模型
- subscriptions 加列 `share_count INTEGER NOT NULL DEFAULT 0`（0=不拼车，≥2=拼车中，1 无意义按 0 处理）
- 新表 `rebates(id INTEGER PK, sub_id INTEGER NOT NULL, date TEXT NOT NULL, amount REAL NOT NULL, note TEXT DEFAULT '', created_at TEXT NOT NULL)`
- 无独立「处置状态」列：share_count≥2 即拼车中；回收是纯账目（TA 拍板：已转让状态语义有缺陷，弃用）

## 净口径计算（_with_rates / stats）
- 拼车份额：monthly_cost_net = monthly_cost / share_count
- 回收冲减：monthly_cost_net -= Σ(rebates.amount) / cycle_months；cycle_months: monthly=1, quarterly=3, semiannual=6, yearly=12, weekly=1（近似，注释说明）
- 单订阅净月均 clamp ≥ 0；回收语义「冲减当前计费期成本」
- 外币订阅：回收金额按该订阅币种记账，折算在 monthly_cost 之后进行（rebate_net = Σamount / months，同币种直接减）
- stats：新增 `monthly_total_net`（净月均合计），`monthly_total` 保持标价口径不动（分类占比图不受影响）

## API
- create/update sub 接收可选 `share_count`（int 0-99，1 视为 0）
- GET/POST /api/subscriptions/{id}/rebates、DELETE /api/subscriptions/{id}/rebates/{rid}
- POST 校验：date ISO 格式、amount>0、note ≤100 字

## 备份兼容

## 前端
- 卡片：meta 行拼车徽章（share_count≥2，flex-wrap 安全）；金额区拼车显示份额+小字「标价 ¥X · 已省 ¥Y」；有回收显示净额+小字「标价 ¥X · 回收 ¥Y」
- 编辑面板：拼车人数输入（0=不拼车）；回收记录区块（列表+记一笔表单：日期/金额/备注）
- 概览月均支出卡：副行显示净口径（标价 > 净时显示，否则不占位）
- i18n zh/en 双语
