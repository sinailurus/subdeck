# 云服务器一键部署（各云通用，以腾讯云轻量为例）

适合「愿意自部署、但没有 NAS」的朋友：买一台最便宜的云服务器，粘贴一条命令，装完即用，全程约 5 分钟。

**适用的机器**：任何 x86_64 架构、装了 Ubuntu 22.04/24.04 或 Debian 12 的云主机，包括但不限于腾讯云轻量应用服务器、阿里云轻量应用服务器、阿里云 ECS、华为云、海外 VPS（Vultr / DigitalOcean 等）。

下文用腾讯云轻量做**示范流程**（界面菜单以腾讯云控制台为例），用其他云的朋友看「步骤 0」的对照表，操作逻辑完全一样，只是菜单名字不同。

---

## ⚠️ 部署前必读：安全与隐私须知

把 SubDeck 装到云服务器上 = 把数据放到**公网上的一台机器**里。和放在家里内网的 NAS 不同，以下风险真实存在，**决定部署前请逐条读完；继续部署即视为已知悉并接受**。

### 1. 传输是明文 HTTP，密码和数据不加密

脚本默认让你用 `http://服务器IP:端口` 访问，**没有 HTTPS**。这意味着：

- 登录密码、订阅内容在公共网络中明文传输，链路上的任意节点（运营商、公共 Wi-Fi 出口、中间设备）理论上可以截获内容；
- 脚本自动生成的随机密码强度足够，但**挡不住明文传输本身**。

如果你对隐私要求高（例如记录了收入相关订阅、不想让任何人有截获机会），两个补救方向：

- **配域名 + HTTPS**：大陆地域的服务器绑域名走 80/443 需要 ICP 备案（腾讯、阿里、华为等大陆机房同样适用）；不想备案可以选香港/境外地域，但延迟略高。配好反向代理后请把 compose 的端口映射改回仅监听 127.0.0.1；
- **降低暴露面**：把防火墙/安全组的来源限制为常用 IP 段（主流云控制台都支持设置来源），或只在需要时临时放行端口。

### 2. 访问密码是唯一防线

SubDeck 是单用户自部署设计：**一把密码，无二次验证、无登录尝试限制**。

- 密码泄露 = 数据泄露 = 任何人可增删改你的订阅记录；
- 请使用脚本自动生成或自行提供的强密码，不要改成 `123456` 这类弱密码；
- 任何在浏览器里保存密码的习惯风险自负。

### 3. 数据存在云服务器磁盘上

订阅数据（SQLite 数据库、上传的 logo、登录密钥）全部存在服务器的 `data/` 目录：

- 云服务商对宿主机磁盘有物理层面的访问能力，这是所有云主机的共同属性；
- **退订或重装服务器前，先备份 `data/` 目录到本地，再自行彻底删除**，避免数据残留在被回收的磁盘上；
- 服务器被入侵的最常见原因不是 SubDeck，而是弱 SSH 密码和过时的系统补丁。请保持系统更新，密码方式登录 SSH 的建议改用密钥。

### 4. 公网扫描是常态，端口只开一个

服务器一上线就会被自动化扫描器盯上。脚本部署只要求开放一个 TCP 端口（默认 8300），**请勿在防火墙开放 Docker 管理端口（2375/2376）或其他无关端口**。

### 5. 维护义务在部署者

- **升级**：`latest` 镜像跟随仓库更新，不自动生效，需要定期手动升级（命令见下文）；
- **备份**：数据备份由你自己负责（`data/` 目录），云服务器不提供针对 SubDeck 的备份保障；
- **免责**：SubDeck 按「现状」提供（MIT 许可证含免责条款），因部署、维护、数据丢失或泄露造成的损失由部署者自行承担。

### 6. 备案边界

- 用 `IP:端口` 直接访问：不需要备案，任何地域都适用；
- 绑域名走 80/443：**中国大陆地域的服务器需要 ICP 备案**（各大陆云厂商均受此约束）；港澳/境外地域不需要。

## 步骤 0：你的云上菜单叫什么（非腾讯云用户看这里）

| 云厂商 | 产品 | 打开网页终端 | 放行端口的位置 |
|---|---|---|---|
| 腾讯云 | 轻量应用服务器 | 「登录」→ 一键登录 | 实例详情 → 「防火墙」页签 |
| 阿里云 | 轻量应用服务器 | 「远程连接」→ 一键远程连接 | 实例详情 → 「防火墙」页签 |
| 阿里云 | ECS 云服务器 | 「远程连接」→ Workbench | 实例详情 → 「安全组」→ 配置规则 |
| 华为云 | 云耀/弹性云服务器 | 「远程登录」 | 「安全组」→ 入方向规则 |
| 海外 VPS | Vultr / DigitalOcean 等 | 本地电脑 SSH 客户端 | 云控制台 Firewall，或系统内 `ufw allow 8300` |

三家大陆云的规则填写方式相同：协议 TCP、端口 8300（或自定义）、来源 `0.0.0.0/0`、策略允许。

## 步骤 1：买服务器（示范：腾讯云轻量）

登录控制台，顶部搜索框搜「**轻量应用服务器**」→ 点「**创建实例**」：

| 选项 | 怎么填 |
|---|---|
| 地域 | 选离自己近的大陆节点（广州/上海/北京都行）。特别在意隐私可选「中国香港」，延迟略高 |
| 镜像 | 选「**操作系统**」页签 → **Ubuntu Server 24.04 LTS**（22.04 也行；不用管「应用镜像」里的 Docker 选项，脚本会自动装） |
| 套餐 | 最低配就行（2核2G 足够，SubDeck 很轻），新用户常有 ¥50~100/年的促销款 |
| 时长 | 按年买比按月划算 |

阿里云轻量、华为云的购买页同理：产品选「轻量应用服务器」，系统镜像选 Ubuntu 24.04，套餐最低档。付款等几分钟，实例状态变「**运行中**」就绪。

## 步骤 2：打开网页终端

实例列表点进你的服务器 → 右上角「**登录**」按钮 → 选「**一键登录**」，这就是浏览器里的网页终端，什么都不用装。

（阿里云入口叫「远程连接」，华为云叫「远程登录」，海外 VPS 用户用本地 SSH 客户端连上去即可。）

进去后看一眼提示符：如果结尾是 `#` 说明已经是 root；如果是 `$`，先敲 `sudo -i` 回车切换到 root。

## 步骤 3：粘贴安装命令

把这一行整段粘贴进终端，回车（粘贴用终端页面的右键粘贴或 Ctrl+Shift+V）：

```bash
curl -fsSL https://cdn.jsdelivr.net/gh/sinailurus/subdeck@main/install.sh | bash
```

等 2~5 分钟（自动装 Docker + 拉镜像）。跑完屏幕最后会打印：

- **访问地址**：`http://服务器IP:8300`
- **访问密码**：一串随机字符 → **马上抄到手机备忘录或密码管理器**，这个大字提醒只在装的时候出现一次

## 步骤 4：放行端口（新手最容易漏的一步）

**不在控制台放行，外网永远访问不了**。以腾讯云为例：实例详情 → 「**防火墙**」页签 → 「**添加规则**」：

| 字段 | 填写 |
|---|---|
| 应用类型 | 自定义 |
| 协议 | TCP |
| 端口 | 8300（或你 `--port` 指定的） |
| 来源 | `0.0.0.0/0`（或你的常用 IP 段，更安全） |

阿里云轻量同样在「防火墙」页签；阿里云 ECS 和华为云在「安全组」里添加**入方向**规则，内容一致。

## 步骤 5：登录

浏览器打开步骤 3 打印的地址，输入访问密码，进去了就全部完成。

## 常用操作

```bash
cd /opt/subdeck

# 查看日志
docker logs -f subdeck

# 升级到最新版（数据不受影响）
docker compose pull && docker compose up -d

# 备份数据
tar czf ~/subdeck-backup-$(date +%F).tar.gz data/

# 修改密码或端口：编辑 .env 后重启
nano .env && docker compose up -d
```

## 迁移与退订

- **迁回 NAS**：拷走 `data/` 目录 → 在 NAS 的 compose 里把 `SUBDECK_DATA` 指到该目录 → 启动即可，登录密钥随密钥文件保留；
- **退订前**：先备份 `data/`，再删掉服务器上的 `/opt/subdeck`，确认清干净后再退订。

## 常见问题

**Q：装完访问不了？**
多数情况是端口没在控制台放行（看步骤 4），其余检查命令是否以 root 跑完、`docker logs subdeck` 有无报错。

**Q：我的云服务器是 CentOS？**
本脚本目前只支持 Ubuntu 22.04/24.04 和 Debian 12。建议在云控制台「重置系统」换成 Ubuntu 24.04 后重新执行。

**Q：端口被别的程序占了？**
`--port 8888` 换一个，同时在控制台放行新端口。

**Q：想绑域名 + HTTPS？**
先过一遍上方「安全与隐私须知」第 1 条和第 6 条：大陆地域需备案，然后自备 Caddy/Nginx 反向代理，并把 compose 端口映射改为 `127.0.0.1:8300:8000` 只监听本机。
