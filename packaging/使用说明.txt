SubDeck Windows 版 — 使用说明
================================

一、三步开始
  1. 解压本压缩包到一个固定文件夹（建议：桌面新建文件夹，或 D:\SubDeck）
  2. 双击 SubDeck.exe
  3. 浏览器会自动打开订阅页面，开始添加你的订阅

二、手机怎么访问
  手机和电脑连同一个 WiFi，手机浏览器输入程序窗口里显示的
  「手机/局域网」地址（形如 http://192.168.x.x:8017）即可。

三、想设访问密码？
  记事本打开 subdeck.ini，在 password = 后面写上密码，
  保存后重新打开 SubDeck.exe。手机访问时也要输这个密码。

四、想把数据放到别的盘？
  记事本打开 subdeck.ini，在 data_dir = 后面写完整路径
  （例如 D:\SubDeckData），保存重启。
  搬家/备份很简单：整个 data 文件夹复制走就行，
  订阅记录、密码、上传的图片全在里面。

五、常见问题
  * 第一次运行弹出「Windows 安全中心警报/防火墙」：
    点「允许访问」（不勾选任何复选框直接点允许也可以）。
    若点了取消，手机将无法访问，重新打开程序再允许一次。
  * 杀毒软件提示拦截：本程序未购买数字签名，部分杀软会误报。
    请在杀毒软件里选择「信任/添加白名单」后再运行。
    建议从 GitHub Release 页面下载本程序，勿用来源不明的版本。
  * 双击没反应：先确认系统是 Windows 10 或以上；
    若杀软已静默删除 exe，先加白名单再重新解压。
  * 端口被占用：程序会自动改用 8018 端口，以窗口提示的地址为准。
  * 停止程序：直接关闭黑色窗口（或按 Ctrl+C）。
  * 开机自动启动：按 Win+R 输入 shell:startup 回车，
    把 SubDeck.exe 的快捷方式放进去即可。

六、卸载
  关闭程序后，直接删除整个文件夹即可，不留残余。

系统要求：Windows 10 / 11（64 位）
数据安全：所有数据只存在你自己的电脑上，程序不联网上传任何数据。
