如何获取邮箱 SMTP 授权码

SubDeck 发提醒邮件时，要你填的不是邮箱的登录密码，而是一串叫「授权码」的专用密码。它是邮箱服务商给第三方软件单独发的通行证，只允许用来收发邮件，不能用来登录网页版邮箱。用授权码的好处是：就算这串码泄露了，别人也进不了你的邮箱。

下面按邮箱品牌分别说明怎么拿到授权码，以及拿到后怎么填进 SubDeck。先用哪家看你自己平时用哪个邮箱。

QQ 邮箱

适用于 @qq.com 和 @foxmail.com 地址。

第一步：开启服务并生成授权码

  1. 用电脑浏览器打开 mail.qq.com，登录你的 QQ 邮箱。
  2. 点页面顶部的「设置」。
  3. 点「账号与安全」。
  4. 往下找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」这一块。
  5. 点「IMAP/SMTP 服务」右边的「开启」。
  6. 按页面提示，用绑定的手机号发一条短信，证明是你本人操作。
  7. 短信验证通过后，页面会弹出一串 16 位的授权码。
  8. 立刻复制这串码，粘到备忘录或密码管理器里存好。

第二步：填入 SubDeck

打开 SubDeck 的「设置」，找到「邮箱提醒」，按下面填：

项目 填什么
SMTP 服务器 smtp.qq.com
端口 465
SSL 加密 勾上
发件邮箱（SMTP 用户名） 你的完整 QQ 邮箱地址，例如 123456789@qq.com
SMTP 授权码 第一步复制的 16 位码

填完点「发送测试邮件」，收到邮件后再点「保存提醒设置」。

注意

  • 授权码只在生成时显示一次，关掉页面就看不到了，当场复制保存。
  • 之后想查看或作废这串码：回到「账号与安全」，进「设备管理」里的「授权码管理」，可以停用或重置。重置后旧码马上失效，SubDeck 里要换成新码。
  • 改了 QQ 密码后，所有授权码全部失效。这时 SubDeck 发信会失败，需要回到第一步重新生成一个。
  • QQ 邮箱每天大约能发 500 封，提醒邮件完全够用。

163 / 126 邮箱

适用于 @163.com 和 @126.com 地址，两家流程一样。

第一步：开启服务并生成授权码

  1. 用电脑浏览器打开 mail.163.com（126 邮箱打开 mail.126.com），登录。
  2. 点页面顶部的「设置」。
  3. 点「POP3/SMTP/IMAP」。
  4. 找到「SMTP 服务」，点开启。
  5. 按页面提示，用绑定的手机号发一条短信。
  6. 验证通过后，页面会显示一串「客户端授权密码」，这就是授权码。
  7. 立刻复制保存。

第二步：填入 SubDeck

打开 SubDeck 的「设置」，找到「邮箱提醒」，按下面填：

项目 填什么
SMTP 服务器 smtp.163.com（126 邮箱填 smtp.126.com）
端口 465
SSL 加密 勾上
发件邮箱（SMTP 用户名） 你的完整邮箱地址
SMTP 授权码 第一步复制的客户端授权密码

填完点「发送测试邮件」，收到邮件后再点「保存提醒设置」。

注意

  • 新注册的邮箱可能开不了 SMTP 服务。有的要先绑定手机号，有的要等一段时间，按页面提示处理。
  • 改了邮箱密码后，授权码失效，需要回到第一步重新生成。
  • 授权码只在生成时显示一次，当场复制保存。

Gmail

适用于 @gmail.com 地址。

第一步：开启两步验证并生成应用密码

  1. 用浏览器打开 myaccount.google.com，登录你的 Google 账号。
  2. 点左侧的「安全」。
  3. 确认「两步验证」已经开启。没开的话先按提示开启，不开的话下一步的入口不会出现。
  4. 在页面顶部的搜索框输入 app password，点搜到的「应用密码」。
  5. 输入一个名字方便自己认，比如 SubDeck。
  6. 点「创建」，页面会显示一串 16 位的密码。
  7. 立刻复制这串码保存。

第二步：填入 SubDeck

打开 SubDeck 的「设置」，找到「邮箱提醒」，按下面填：

项目 填什么
SMTP 服务器 smtp.gmail.com
端口 465
SSL 加密 勾上
发件邮箱（SMTP 用户名） 你的完整 Gmail 地址
SMTP 授权码 第一步复制的 16 位应用密码

填完点「发送测试邮件」，收到邮件后再点「保存提醒设置」。

注意

  • 必须先开两步验证，否则「应用密码」的入口不会出现。
  • 16 位密码里有空格的话，连同空格一起原样粘贴，不要自己删。
  • 改了 Google 账号密码后，应用密码会被全部撤消，SubDeck 发信会失败，回到第一步重新生成一个填进来。
  • Gmail 每天大约能发 500 封，提醒邮件完全够用。

iCloud 邮箱

适用于 @icloud.com、@me.com、@mac.com 地址。

第一步：生成 App 专用密码

  1. 用浏览器打开 account.apple.com，登录你的 Apple 账户。
  2. 点「登录与安全」。
  3. 点「App 专用密码」。
  4. 点「+」号，输入一个标签名方便自己认，比如 SubDeck。
  5. 点「完成」，页面会显示一串密码。
  6. 立刻复制保存。这串密码中间带连字符，形如 xxxx-xxxx-xxxx-xxxx，连字符要一起复制，整串是 16 位字母。

第二步：填入 SubDeck

打开 SubDeck 的「设置」，找到「邮箱提醒」，按下面填。这一家的填法和别家不一样，看仔细。

项目 填什么
SMTP 服务器 smtp.mail.me.com（不是 icloud.com）
端口 587（不是 465）
SSL 加密 不勾（关掉）
发件邮箱（SMTP 用户名） 你的完整 iCloud 邮箱地址
SMTP 授权码 第一步复制的 App 专用密码，含连字符

填完点「发送测试邮件」，收到邮件后再点「保存提醒设置」。

注意

  • 必须 Apple 账户已开启双重认证，大多数人是开着的。没开的话先去「登录与安全」里开启。
  • 服务器、端口、SSL 三项和别家不同，照上面的表填，不要照着 QQ 那节的填。
  • 改了 Apple 账户密码后，所有 App 专用密码全部失效，需要回到第一步重新生成。

Outlook 邮箱（部分账号已不可用）

适用于 @outlook.com、@hotmail.com、@live.com、@msn.com 地址。

第一步：生成应用密码

  1. 用浏览器打开 account.microsoft.com，登录你的微软账号。
  2. 点「安全」。
  3. 找到「高级安全选项」，点进去。
  4. 确认「两步验证」已经开启。没开的话先按提示开启。
  5. 往下找到「应用密码」，点「创建新应用密码」。
  6. 页面会显示一串密码，立刻复制保存。

第二步：填入 SubDeck

打开 SubDeck 的「设置」，找到「邮箱提醒」，按下面填：

项目 填什么
SMTP 服务器 smtp-mail.outlook.com
端口 587
SSL 加密 不勾（关掉）
发件邮箱（SMTP 用户名） 你的完整 Outlook 邮箱地址
SMTP 授权码 第一步复制的应用密码

填完点「发送测试邮件」，收到邮件后再点「保存提醒设置」。

注意

  • 微软正在逐步取消「用应用密码直接登录 SMTP」这种方式，你的账号可能已经无法用这个方法发信。 如果测试发送时报 authentication unsuccessful 一类的错误，就是这个原因。
  • 这是微软对账号安全策略的调整，和 SubDeck 无关，SubDeck 这边没有可以改的设置。
  • 遇到这种情况，建议换用前面几家邮箱（QQ、163、Gmail）来发提醒邮件。

常见问题

授权码粘进去显示不对，或者发送测试失败

先检查授权码前后有没有带空格。复制的时候多选了一个空格，邮箱服务商就会判定密码错误。重新复制一遍，只选那串码本身。

换了邮箱密码之后，SubDeck 就发不出邮件了

所有邮箱都一样：改了登录密码，之前的授权码就作废了。回到对应邮箱那一节，重新生成一个授权码，填进 SubDeck 就能恢复。

显示发送成功，但邮箱里没收到邮件

先去垃圾箱、广告邮件、订阅邮件这类文件夹翻一翻，提醒邮件经常被分到那里。找到了就把它标记为「不是垃圾邮件」，之后的邮件就会正常进收件箱。

测试发送失败，授权码确认没填错

对照本文各家「第二步」的表格，逐项检查三样：SMTP 服务器、端口、SSL 加密开关。最容易错的是 iCloud 和 Outlook，这两家是 587 端口加 SSL 关闭，和 QQ、163、Gmail 的 465 加 SSL 开启正好相反。

发件邮箱和收件邮箱可以不一样吗

可以。发件邮箱填哪个账号的，就用哪个账号的授权码；收件邮箱随便填，多个用逗号分开。

填好了多久会收到提醒

启用提醒后，SubDeck 每天在你设定的时间检查一次，把未来几天内到期的订阅汇总成一封邮件发出。想马上验证配置是否正确，用「发送测试邮件」，不用等到设定时间。
